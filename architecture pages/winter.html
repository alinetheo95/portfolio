WINTER ESTATES

FREELANCE | 2024

1 / 5

This project features schematic architectural drawings and interior renderings done for a kitchen renovation in Brookfield, CT. The client was looking to update the outdated finishes of the space for a more modern look, better windows and doors to allow for more light, and an open floor plan to better utilize the space. This project involved site visits, project coordination, and design development and documentation in working with the owner and contractor.
